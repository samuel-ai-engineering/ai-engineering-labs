# Student Start Here

You do not need to install Python or learn Git commands before starting the labs. A web browser, a Google account, and a GitHub account are enough.

## After Accepting the Organization Invitation

1. Sign in to GitHub.
2. Open the [samuel-ai-engineering organization](https://github.com/samuel-ai-engineering).
3. Open the `ai-engineering-labs` repository.
4. Select the folder for the current week.
5. Open the notebook and click **Open in Colab**.
6. In Colab, select **File > Save a copy in Drive**.
7. Complete the exercise in your personal copy.
8. Submit the requested Colab link through GOMYCODE.

## Sharing a Colab Submission

1. Open the completed notebook in Colab.
2. Select **Share**.
3. Change access to **Anyone with the link** only when the instructor requests a shareable link.
4. Keep the role set to **Viewer**.
5. Submit the link through GOMYCODE.

Never include an API key, password, private dataset, or another student's work in a shared notebook.

## When Project Work Begins

The instructor will provide a GitHub project template. You will create your own repository from that template instead of editing this shared repository.

Until that lesson, you do not need to use `git clone`, branches, pull requests, or terminal commands.

## Getting Help

When reporting an error, include:

- the week and notebook name
- the exact error message
- the code cell that produced it
- what you expected to happen

Remove all API keys and personal information before sharing screenshots or code.
