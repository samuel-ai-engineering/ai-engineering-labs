# Week 1: Colab and Python Foundations

## Learning Objectives

By the end of this lab, students should be able to:

- identify Markdown and code cells
- run cells in order
- install a Python package in Colab
- identify the active runtime
- store a secret without exposing it in notebook code
- save and share a copy of a notebook safely

The first teaching notebook will be added here after it has been tested in a fresh Colab runtime.
