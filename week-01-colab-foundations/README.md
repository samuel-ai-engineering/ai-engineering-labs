## Learning Objectives

By the end of this lab, students should be able to:

- write assignment and expression statements
- continue long expressions across multiple lines
- use indentation to define code blocks
- write useful comments and docstrings
- import modules and specific names
- display output and handle values returned by `input()`
- run and save a notebook in Google Colab
